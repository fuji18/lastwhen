# 要求: カードをタップして開く詳細シート(Issue #22 / F29)

## 背景・目的

一覧は「何日前」と紙の古び方だけを見せる。**もう一段だけ知りたいとき**に、タップで最小限の情報を出す。

```
最後：14日前
前回：7日間隔
そろそろかも。
```

**この 3 行以上を出さない。** 統計画面でもグラフでもない。「前回の周期に照らして今どうか」が 1 秒で分かれば役目は終わる。

## ユーザー判断(2026-09-23 確定)

- **カードのタップ → 詳細シート**。編集画面へは**シート内の「編集」ボタン**から行く
- 長押しで詳細を出す案は採らない(長押しは見つけてもらえず、製品の中心機能が隠れる)
- 削除の入口は従来どおり**編集画面の中だけ**(F7)

## スコープ

- 詳細シート(`showModalBottomSheet`)の新設: `lib/ui/widgets/item_detail_sheet.dart`
- 一覧のカードのタップの行き先を、編集画面から詳細シートに変える
- 経年ステージ → 3 行目の文言の写像
- ウィジェットテスト・既存テストの追従
- ドキュメント追記(PRD の F29 / 機能設計の画面遷移図と UI 設計 / 用語集)

## スコープ外

- 履歴の一覧表示・グラフ・統計(F23)
- 基準間隔そのものの表示(学習値を見せると設定したくなり、F9 を呼び込む)
- シートからの「やった」記録 / 削除 / メモ(F21)・写真(F22)・カテゴリ(F13)
- 状態層(`lib/state/`)・データ層(`lib/data/`)の変更。必要な値は `ItemView` に揃っている

## 受け入れ条件

- [ ] カードをタップすると詳細シートが開く
- [ ] 1 行目が `最後：14日前` 形式で出る(`今日` / `昨日` は一覧と同じ表記)
- [ ] 未実施の項目では「まだ記録がありません」だけが出る
- [ ] 2 行目が `前回：7日間隔` 形式で出る。記録が 1 件以下なら行ごと出ない
- [ ] 3 行目は相対経過度 `1.0` 以上のときだけ出る(`null` では出ない)
- [ ] 表示はこの 3 行まで(見出しの項目名を除く)。履歴一覧・グラフ・統計・基準間隔を出さない
- [ ] シートから編集画面へ到達できる
- [ ] 削除の入口はシートに無い
- [ ] シートを開くときに取り消し導線(`SnackBar`)を閉じる
- [ ] 色・余白・タイポがすべて `Theme.of(context)` 経由
- [ ] スクリーンリーダーで各行が順に読み上げられる
- [ ] 文字サイズ 200% でシートが破綻しない
- [ ] ウィジェットテスト(通常の 3 行 / 未実施 / 記録 1 件のみ / 相対経過度 1.0 未満)
- [ ] `dart format` / `flutter analyze --fatal-infos` / `flutter test` が通る
