# 要求: 過去の日付で記録する(F16 / Issue #49)

## 背景

「やった」を押し忘れた日を後から入れられない。忘れたまま押すと当日で記録され、経過日数も
基準間隔(F27)の学習もずれる。PRD F16(最終実施日の手動修正)を「過去の日付で記録する」として実装する。

- **スコープ判断(司令塔)**: P1。残りチケットが P1 のみとなり、ユーザーが着手を承認済み(2026-09-26)

## ユーザーの判断(2026-09-26)

- アプリを日本語ロケール(`ja`)にする。`flutter_localizations`(SDK 同梱)を追加する → **司令塔が追加済み**
- 「日付を指定して記録」は一覧・図鑑のどちらから開いた詳細シートにも出す

## 受け入れ条件(Issue #49 より)

- [ ] 項目に過去の日付(今日を含む)で実施を記録できる。未来日は選べない
- [ ] 記録した日付が最新であれば、一覧の経過日数・最終実施日に反映される
- [ ] 過去日の記録が `done_logs` に入り、基準間隔の学習(直近最大 5 間隔の中央値)に正しく使われる
- [ ] 日付は端末のローカル暦日で選び、UTC で保存される(経過日数は暦日の差で数える)
- [ ] 「やった」には確認ダイアログを出さない方針を崩していない
- [ ] ドメイン/リポジトリ/状態管理のテストと、操作のウィジェットテストがある
- [ ] `dart format` / `flutter analyze --fatal-infos` / `flutter test` が通る

## スコープ外

- 実施履歴の一覧表示・個別の履歴の削除/編集
- 未来日の記録
- 「やった」ボタン自体の挙動変更
- DB スキーマの変更(`lib/data/database/` / `lib/data/migrations/` に触れない)
