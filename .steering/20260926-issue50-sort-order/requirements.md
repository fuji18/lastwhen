# 要求: 一覧の並び替え(F15 / Issue #50)

## 背景

既定の並び(F30: 相対経過度の降順)は実装済みだが、名前で探したい・登録した順に見たいときに
切り替える手段がない。PRD F15(並び替え)の選択 UI を実装する。

- **スコープ判断(司令塔)**: P1。残りチケットが P1 のみで、ユーザーが P1 の着手を承認済み

## ユーザーの判断(2026-09-26)

- 並び順の選択は**保存しない**(再起動で経年順に戻る。F13 と同じ方針)
- UI は **AppBar の並び替えボタン → メニュー**。選択中の候補にチェック
- 名前順は**かなを正規化して文字コード順**で比べる(漢字は読み順にならない制約を docs に明記)
- **図鑑は常に経年順**(一覧で選んだ並びに追従しない)

## 受け入れ条件(Issue #50 より)

- [ ] 一覧で並び順を選べ、選んだ順で表示される。既定は F30 の並び
- [ ] 「記録操作では並びを組み替えない」(F30)を、どの並び順でも保つ
- [ ] カテゴリの絞り込み(F13)と併用でき、絞り込み後も選んだ並びを保つ
- [ ] 未実施の項目の位置が並び順ごとに定義どおりになる(経過日数順では下部にまとめる)
- [ ] 名前順は日本語の項目名で破綻しない(比較方法を design.md に明記する)
- [ ] 並び順ごとのユニットテストと、切り替えのウィジェットテストがある
- [ ] `dart format` / `flutter analyze --fatal-infos` / `flutter test` が通る

## スコープ外

- 手動のドラッグ並べ替え(`sortOrder` の書き換え)
- 図鑑(F31)の並び順の変更・図鑑の並び替え UI
- データ層のクエリ変更・DB スキーマの変更
- 選択の保存(ユーザー設定の保存先)
