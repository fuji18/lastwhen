# 要求: よくある項目のワンタップ追加(F17 / Issue #67)

## 背景

F17(テンプレート項目)は PRD で P2 だが、KPI「初回 3 件以上登録 50%」に最も効く機能として
「最初に前倒しを検討する候補」とされている。Android 先行リリースの前に入れ、初回起動から
項目が揃うまでの手間を減らす。P1 へ前倒しする。

## スコープ

- よくある項目 6 件(歯ブラシ交換・美容院・エアコン掃除・歯医者・洗車・布団干し)を定義する
- **一覧の空状態**: よくある項目をチップで並べ、**1 タップで未実施の項目として追加**する(確認なし)
- **登録画面**: 登録済みの項目と同名でないよくある項目をチップで並べ、タップで項目名とアイコンを入力欄に入れる(保存は通常どおり)
- 追加は既存の `ItemListNotifier.addItem` を通す(トリム・長さ検証・`sortOrder` の採番)
- docs: PRD の F17 を P2 → P1 に移し前倒しの理由を追記 / functional-design に振る舞いを追記 / glossary に「よくある項目」を追加

## スコープ外

- よくある項目のユーザーによる追加・編集
- 初回起動時のオンボーディング画面
- よくある項目から追加した項目への初期の記録
- スキーマ・マイグレーションの変更(`lib/data/database/` / `lib/data/migrations/` に触れない)

## 受け入れ条件

- [ ] 一覧の空状態からよくある項目を 1 タップで追加でき、追加した項目が一覧に**未実施**で表示される
- [ ] 同名の項目が既にあるよくある項目は登録画面に出さず、空状態では二度押しを塞ぐ。同じ名前の二重登録が起きない
- [ ] 追加に確認ダイアログを出さない
- [ ] 文言が docs/glossary.md の表記に従っている(**項目**)
- [ ] PRD / functional-design が更新されている
- [ ] ウィジェットテストで、空状態 → 1 タップ → 一覧に出る、を確認している
