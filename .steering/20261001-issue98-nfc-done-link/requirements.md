# 要求内容: NFC タグをかざして「やった」を記録する(Android・URL 起動方式)(#98)

## 背景

ユーザーからの要望。実施する場所に NFC タグを貼っておき、スマホをかざすだけで項目を記録できるようにしたい。
アプリを開いて項目を探してタップする手間が省け、「1 タップで記録」という中心的価値をさらに短くできる。

方式は **NFC タグに項目ごとの URL を書き込み、OS がタグを読んでアプリを起動し、アプリが URL を受けて記録する**。
アプリ自身は NFC を読まない(NFC の権限・パッケージを足さない)。

## スコープ

- Android で `lastwhen://done/<項目ID>` の URL を受けてアプリを起動できるようにする(コールドスタート・起動中の両方)
- URL を受けたら、その項目を記録する。「やった」と同じ `markDone` を通す
- 結果をスナックバーで知らせる(記録した / 今日はもう記録済み / 見つからない / 保存失敗)。記録したときは取り消しを付ける
- 記録の詳細のメニューから、その項目の URL を表示・コピーできるようにする。使い方の短い説明を添える
- PRD に F32 を足す。functional-design・glossary を更新する

## スコープ外

- iOS 対応(Universal Link が要る。iOS 公開の保留が外れたら別チケット)
- アプリからタグへ直接書き込む機能
- 画面を出さずに裏で記録する
- 過去日付・メモ付きの記録をタグから行うこと

## 受け入れ条件

- [ ] `lastwhen://done/<id>` で起動すると、その項目の最終実施日が今日になる(コールド・起動中の両方)
- [ ] 記録後にスナックバー「「<項目名>」を記録しました」と「取り消す」が出て、取り消すと直前の最終実施日(未実施なら未実施)に戻る
- [ ] 確認ダイアログは出ない
- [ ] 今日すでに記録済みの項目では書き込まず「「<項目名>」は今日すでに記録しています」と出す(リンク経由のみ。ボタンの「やった」は変えない)
- [ ] 削除済みの項目・形式が不正な URL では何も書き込まず「この項目は見つかりませんでした」と出す
- [ ] 記録の詳細のメニュー「NFC タグに登録」から URL を表示・コピーできる
- [ ] 記録の完了を待ってから表示を変える(楽観的 UI 更新をしない)
- [ ] PRD(F32)・functional-design・glossary が更新されている
- [ ] URL の生成・解釈のユニットテスト、`markDoneFromLink` のテスト、リンク受信 → スナックバーのウィジェットテストがある
- [ ] 既存テストがすべて通る
