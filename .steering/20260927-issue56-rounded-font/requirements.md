# 要求: 丸ゴシック系フォントを同梱する(Issue #56)

## 背景

画面イメージ(`docs/ideas/LastWhen_gamen.png`)は丸みのある日本語書体で組まれているが、現状は `pubspec.yaml` の
`fonts:` がコメントアウトのままで、端末標準のフォントで描かれている。書体を同梱して画面イメージの印象に寄せる。
配色(#55)に続く「画面イメージへの寄せ」の 2 本目。

## スコープ

- 丸ゴシック系の日本語フォントを選び、アプリに同梱する(`assets/fonts/` + `pubspec.yaml` の `fonts:`)
- `ThemeData` の `fontFamily` / `TextTheme` に適用する(経過日数を最大・最も太くする強調規則は保つ)
- ライセンス表記を同梱する(`LicenseRegistry` への登録)
- docs の更新: `architecture.md` の依存表と `ui-design-guidelines.md` §7 にフォントを追記する

## スコープ外

- ロゴの手書き風文字をアプリ内に出すこと(画面構成の変更にあたる)
- 配色(#55・済)・紙の質感(#57)
- **ライセンス一覧を開く画面の入口**(マイページは中身が決まるまで置かない方針。登録だけを済ませる)

## 受け入れ条件(Issue #56 より)

- [ ] 全画面の日本語・英数字が同梱フォントで描かれる
- [ ] 文字サイズ 200% で既存のレイアウト検査(`accessibility_test.dart`)が通る
- [ ] フォントのライセンスがアプリ内のライセンス一覧に出る
- [ ] APK のサイズ増加を PR に記載する
- [ ] `dart format` / `flutter analyze --fatal-infos` / `flutter test` が通る

## 判断(2026-09-27)

- 書体は **Zen Maru Gothic**、ウェイトは **Regular / Medium / Bold** の 3 つ(ユーザーが選択)
- **サブセット化しない**(項目名は自由入力。欠けた字だけ端末フォントに落ちるのを避ける)
- 「ライセンス一覧に出る」は、アプリにまだ一覧画面が無いため **`LicenseRegistry.licenses` に載ることをテストで検査**して担保する(design.md 判断 D)
- 「200% の検査が通る」は、ウィジェットテストが既定で使うテスト用フォントのままでは実フォントの寸法を測れないため、
  **`accessibility_test.dart` で同梱フォントを実際に読み込んでから**既存の検査を回す(判断 E)
