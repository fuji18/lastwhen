# 要求: 記録の履歴を日付ごとに削除できるようにする(Issue #63)

## 背景

誤って記録したとき、「やった」の取り消し導線(4 秒)を逃すと記録を消す手段がない。誤った記録は
基準間隔・経年ステージ・並び順・通知のすべてに効き続ける。「記録の詳細」(#58)の履歴から、
日付ごとに記録を削除できるようにする。P2 として起票され、**2026-09-28 にユーザーが論点を確定**した。

## ユーザーが確定した判断(2026-09-28)

| 論点 | 決定 |
| --- | --- |
| 誤操作の救い方 | **確認ダイアログ + 削除後 4 秒の取り消し**(「削除には確認を入れる」をそのまま守る) |
| 操作の入口 | **履歴の各行の右端に削除ボタン**(アイコン、タップ領域 48dp 以上、読み上げ可能) |
| 同じ暦日に複数の記録がある行 | **その暦日の記録をすべて消す**(画面の 1 行 = 消える単位) |
| 進め方 | #58 とは別チケット・別 PR |

## スコープ

- 履歴の各行に削除ボタンを置き、確認ダイアログを経て、その**ローカル暦日**の `done_logs` をすべて消す
- `last_done_at` を残りの履歴の最大値(無ければ NULL = 未実施)に揃える
- 削除後に「M月d日の記録を削除しました」+「取り消す」を 4 秒出す。取り消すと元の日時で戻す
- docs 更新: PRD(F29・F12 の設計判断)、`functional-design.md`、`glossary.md`

## スコープ外

- 履歴の日付の編集 / 11 件目以降の表示・削除 / カードからの履歴削除 / 複数行の一括削除
- スキーマ・マイグレーションの変更(`lib/data/database/` / `lib/data/migrations/` に触れない)

## 受け入れ条件

- [ ] 履歴の各行に削除ボタンがあり、確認ダイアログを経て削除できる(キャンセルでは何も起きない)
- [ ] 同じ暦日の記録がまとめて消える
- [ ] 削除後 4 秒間取り消しでき、取り消すと履歴・最後にやった日・平均の間隔が元に戻る
- [ ] 最新の日を消すと最後にやった日が 1 つ前の記録に戻る。全件消すと未実施になる
- [ ] 削除に失敗したときは履歴が変わらず、失敗を知らせる
- [ ] 文字サイズ 200% で破綻せず、削除ボタンが読み上げで操作できる(ラベルに日付を含む)
- [ ] `dart format` / `flutter analyze --fatal-infos` / `flutter test` が通る
