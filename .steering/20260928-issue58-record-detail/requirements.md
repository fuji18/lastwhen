# 要求: 詳細シートを「記録の詳細」画面に作り替える(Issue #58)

## 背景

画面イメージ(`docs/ideas/LastWhen_gamen.png` 中央)の「記録の詳細」は、項目ごとの専用画面に
最後にやった日・平均の間隔・前回からの間隔(「いつもより長め」)・一言・記録の履歴・「記録する」ボタンを並べている。
現状の詳細シート(F29)は「最大 3 行・履歴一覧・統計・基準間隔は出さない」と PRD で決めており、画面イメージと逆向き。
P2 として起票され、**2026-09-28 にユーザーが着手を承認**した。

## ユーザーが確定した判断(2026-09-28)

| 論点 | 決定 |
| --- | --- |
| 着手 | する(PRD の F29 を改める) |
| シートか専用画面か | **専用画面に置き換える**(push 遷移の全画面。シートは廃止) |
| 履歴の件数 | **直近 10 件**(既存の `recentDoneAts` を流用。リポジトリにクエリを足さない) |
| 「過去8回の平均」 | **表記を合わせる**。基準間隔の定義(直近最大 5 間隔の中央値)は変えず、「過去N回の」を付けずに「平均の間隔」と表記する |

## スコープ

- PRD の F29 を新仕様に改め、変更理由を設計判断として残す。F23 との切り分けを書く
- 「記録の詳細」画面(`ItemDetailScreen`)を作る
- 一覧・図鑑のカードのタップで、この画面へ遷移する(シートを開かない)
- docs 更新: PRD(F29 / F31)、`functional-design.md`(詳細節・画面遷移図・UC1b・図鑑節・テスト表)、`glossary.md`、`repository-structure.md`

## スコープ外

- 下部ナビの「マイページ」
- 履歴の個別削除・編集
- 一覧の「やった」ボタンを外すこと
- 11 件目以降の履歴表示(全件クエリ)
- 基準間隔の定義変更

## 受け入れ条件

- [ ] PRD の F29 が新しい仕様に改められ、変更の理由が設計判断として残っている
- [ ] 一覧・図鑑のカードから「記録の詳細」を開ける
- [ ] 履歴が新しい順に、日付と前回からの間隔つきで並ぶ(未実施・記録 1 件のときの表示が決まっている)
- [ ] 平均の間隔が、記録 1 件以下では「学習中」になる
- [ ] 「記録する」で記録でき、確認ダイアログを出さず、取り消しができる
- [ ] 過去の日付で記録する(F16)への入口を保つ
- [ ] 文字サイズ 200% で破綻しない
- [ ] `dart format` / `flutter analyze --fatal-infos` / `flutter test` が通る
