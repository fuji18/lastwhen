# 要求: 相対経過度でカードが古びていく表示(Issue #21 / F28)

## 目的

期限を管理せず、**その人の生活リズムから外れているほど紙が古びる**ことで「そろそろ」を伝える。
見た目を決めるのは絶対日数ではなく**相対経過度**(#20 で `ItemView.relativeElapsed` に搭載済み)。
同じ「14日前」でも、基準間隔 7 日の項目と 180 日の項目はまったく違う見た目になる。

要求の全文と受け入れ条件は Issue #21 の本文が正。

## このチケットでやること

- 相対経過度 → 経年ステージ(5 段階)の判定(ドメインの純関数)
- `ItemView` に経年ステージを持たせる(変換時に 1 回だけ算出)
- ステージごとの紙の色を `ThemeExtension`(`AgingPalette`)で定義(ライト / ダーク)
- 一覧の行を**カード**(`ItemCard`)に置き換え、`CustomPainter` で紙の面・黄ばみ・シミ・縁の傷み・欠けを描く
- スクリーンリーダーにステージを伝える
- ユニットテスト・ウィジェットテスト・コントラスト検査
- ドキュメント追記(PRD F28 / 機能設計「色の使い方」/ UI ガイドライン §7 / 用語集)

## やらないこと

- 詳細画面(#22)・並び順(#23)・目安期間の手動設定(F9)・通知(F11)
- ステージが変わる瞬間のアニメーション(静的な描画のみ)
- 基準間隔の算出そのもの(#20 で完了)
- **アイコンの掠れ**: 項目アイコンは #32 で入る。#21 はアイコンを置かない(下記の決定)
- **カードへの「平均 N日」/「学習中」の表示**: 出さない(下記の決定)

## 計画時の決定(2026-09-23、ユーザー確認済み)

1. **紙の質感は `CustomPainter` で手続き的に描く**(Issue の推奨案)。画像アセットは持たない。追加依存なし
2. **アイコンの掠れは #32 へ送る。** #21 の形状変化は「シミ・縁の焼け・端の傷み(ギザギザ)・欠け」で作る。
   `ItemCard` が経年ステージを持つので、#32 がアイコンを足すときに掠れを掛ける(#32 に申し送る)
3. **カードに「平均 N日」/「学習中」を出さない。** Issue #21 のスコープに無い。基準間隔が `null` の項目は
   「古びない紙」で表すだけにする。用語集の「null のとき画面上は『学習中』」は、表示するときの文言として残す
