# 要求: 配色を画面イメージに合わせる(Issue #55)

## 背景

画面イメージ(`docs/ideas/LastWhen_gamen.png`)はクリーム地・テラコッタ(赤茶)のアクセント・焦げ茶の文字で組まれているが、
現状は青のシード色 1 つから `ColorScheme.fromSeed` で全色を生成しており、ボタン・ナビ・背景が Material 3 標準の青系になっている。
アプリ全体の配色を画面イメージに合わせる。以降のフォント(#56)・紙の質感(#57)・詳細画面(#58)の参照実装になる。

## スコープ

- 画面イメージから色を採り、`ColorScheme` のロールに割り当てる(背景・面・primary = テラコッタ・文字 = 焦げ茶)
- ライト / ダークの両方を定義する(ダークは画面イメージに無いので、同じ色相で組む)
- 下部ナビ・FAB・チップ・ボタン・AppBar が新しい配色で描かれる
- `AgingPalette`(紙の色)と新しい配色の整合をとる
- docs の更新: `ui-design-guidelines.md` §7 の「シード色 1 つ」の記述、`functional-design.md`「色の使い方」の配色表

## スコープ外

- フォント(#56)・紙の質感(#57)・画面構成の変更(詳細シートの作り替えは #58)
- ユーザーによるテーマ切替(F25)
- 部品ごとの形状・余白の変更(色以外の component theme は触らない)

## 受け入れ条件(Issue #55 より)

- [ ] 一覧・図鑑・登録・編集・詳細シート・カテゴリ管理の全画面で、青系の色が残っていない
- [ ] ライト / ダークの両方で、主要テキストのコントラストが 4.5:1 以上、アイコン・枠線が 3:1 以上(テストで検査する)
- [ ] 色はすべて `Theme.of(context)` 経由で参照し、ウィジェット内に生の値を書かない
- [ ] 既存の経年ステージのコントラスト検査が通る
- [ ] `dart format` / `flutter analyze --fatal-infos` / `flutter test` が通る

## 司令塔の判断(2026-09-27)

- `fromSeed`(テラコッタ・`tonalSpot`)を土台に、画面イメージに効くロールだけ `copyWith` で上書きする(design.md 判断 A)
- ダークは同じ色相の焦げ茶地・クリーム文字・明るいテラコッタで組む(判断 C)
- `AgingPalette` の値は変えない(判断 D)
