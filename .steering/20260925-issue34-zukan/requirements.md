# 要求内容: 下部ナビと図鑑画面(Issue #34 / F31)

## 概要

下部ナビ(ホーム / 図鑑)を導入し、1 回以上記録した項目のカードをグリッドで並べる**図鑑**画面を追加する。

## 背景

画面イメージ(`docs/ideas/LastWhen_gamen.png`)には下部ナビと図鑑があり、「記録した項目は図鑑にコレクションされ、
暮らしの記録が並んでいく」体験が描かれている。PRD に記載が無かったため、着手時に F31(P2)として追記した。

## Issue の未決事項に対するユーザーの決定(2026-09-25)

| 未決事項 | 決定 |
| --- | --- |
| 図鑑に載る条件 | **1 回以上記録した項目だけ**(未実施の項目は載らない) |
| 図鑑でできること | カードのタップで**詳細シート**を開く。**項目名の検索**とカテゴリの絞り込みを置く |
| 下部ナビの構成 | **ホーム / 図鑑の 2 つ**。マイページは中身が決まるまで置かない |
| 「+」(項目の追加)の置き場所 | **現行のホームの FAB を維持する**(ナビの中に移さない) |

## 実装対象の機能

### 1. 下部ナビ
- `NavigationBar` で「ホーム」(現行の一覧)と「図鑑」を切り替える
- 起動直後はホーム。タブを切り替えるときは取り消し導線(`SnackBar`)を閉じる

### 2. 図鑑画面
- 1 回以上記録した項目のカードをグリッドで並べる(アイコン・項目名・`平均7日` / `学習中`、紙の古び)
- カテゴリのチップで絞り込む(選択はホームと独立)
- AppBar の検索ボタンから項目名で検索する(部分一致・英字の大文字小文字を区別しない)
- カードをタップすると詳細シートを開く(そこから編集へ進める)
- 記録の入口・項目の追加導線は置かない

### 3. ドキュメント
- PRD(F31)・機能設計(画面遷移図・UI 設計・パフォーマンス)・用語集(図鑑)を更新する(**計画時に司令塔が更新済み**)

## 受け入れ条件

### 下部ナビ
- [ ] 起動直後はホーム(一覧)が表示され、下部ナビに「ホーム」「図鑑」の 2 つがある
- [ ] 「図鑑」をタップすると図鑑に、「ホーム」をタップすると一覧に戻る。一覧のスクロール位置・絞り込みは保たれる
- [ ] 記録直後の取り消し導線はタブを切り替えると消える

### 図鑑画面
- [ ] 未実施の項目は図鑑に載らない。1 回以上記録した項目は載る
- [ ] 基準間隔がある項目は `平均N日`(四捨五入)、無い項目は `学習中` と出る
- [ ] カテゴリのチップで絞り込める。ホームの絞り込みとは独立している
- [ ] 検索で項目名の部分一致に絞れる。検索を閉じると全件に戻る
- [ ] 記録済み 0 件・絞り込み結果 0 件のそれぞれで専用の文言が出る
- [ ] カードをタップすると詳細シートが開く
- [ ] 文字サイズ 200% でオーバーフローが起きない
- [ ] 表記ゆれの禁止語を描画しない(既存の用語テストの対象に図鑑を加える)

## スコープ外

- マイページ
- 図鑑専用の並び替え(並びはホームと同じ F30)
- 図鑑からの記録(「やった」)・項目の追加
- 検索・絞り込みの状態の保存
- ゲーミフィケーション要素(F24)
