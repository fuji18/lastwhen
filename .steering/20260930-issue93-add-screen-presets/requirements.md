# 要求内容: 項目の追加画面でよくある項目を減らし、保存ボタンを常に見せる(#93)

## 背景

実機確認(#90)で出た要望。項目の追加画面で「よくある項目から選ぶ」のチップ(最大 6 個)が縦に場所を取り、
「保存」ボタンが画面外に押し出される。スクロールしないと保存できず使いづらい。

## スコープ

- 追加画面(`lib/ui/screens/item_add_screen.dart`)で出すよくある項目の数を減らす
- 「保存」ボタンが画面内に常に見えるようにする(キーボード表示中も含む)
- 一覧の空状態(`lib/ui/widgets/empty_state.dart`)のチップ列は今のまま変えない

## スコープ外

- よくある項目の中身(`lib/domain/item_template.dart` の 6 件)の変更
- ユーザーによるよくある項目の追加・編集
- 編集画面(`item_edit_screen.dart`)のレイアウト変更(必要と判明したら別チケット)

## 受け入れ条件

- [ ] 追加画面を開いた直後(キーボード表示中)に「保存」ボタンが見えている。小さい画面(360×640dp)でも見える
- [ ] 追加画面に出るよくある項目が 3 件以下になっている
- [ ] 登録済みと同名のよくある項目は出さない、は現状どおり
- [ ] 一覧の空状態のチップ列は変わっていない
- [ ] 文字サイズ最大(200%)でも保存に到達できる
- [ ] PRD F17 行・functional-design の該当節が更新されている
- [ ] ウィジェットテストがある(小さい画面サイズで保存ボタンが表示範囲にあること)
- [ ] 既存の判断(保存中は二度押しを塞ぐ・保存完了を待ってから戻る)が崩れていない
