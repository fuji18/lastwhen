# 要求内容: 項目ごとのアイコン設定(Issue #32 / F14)

## 概要

項目にアイコンを 1 つ持たせ、登録・編集画面で選べるようにする。一覧カードと詳細シートに表示する。

## 背景

画面イメージ(`docs/ideas/LastWhen_gamen.png`)の一覧・詳細・図鑑は、どれも項目ごとのアイコン(風呂・ゴミ箱・植物…)が主役になっている。
F14 は P1。P0 はすべてクローズ済みで、MVP 完了後の P1 として着手する(前倒しではない)。
あわせて #21 から申し送られた「アイコンの掠れ(経年ステージ)」をここで掛ける(`docs/functional-design.md`「色の使い方」末尾)。

## 実装対象の機能

### 1. アイコンの保存
- `items` に `icon` 列(NULL 許容)を足す。スキーマ v3 のマイグレーション
- **NULL = 未選択**。未選択の項目は既定アイコンで表示する
- 既存の項目は移行後も未選択(NULL)のまま。記録・履歴は一切変わらない

### 2. 登録・編集画面でのアイコン選択
- 候補は **Material Symbols(`Icons.*`)から 24 個 + 「指定なし」**(下記「未決の決定」)
- 選ばなくても登録できる(PRD F2「項目名のみの入力で登録が完了する」を守る)
- 編集画面では現在のアイコンが選ばれた状態で開き、変更・「指定なし」への戻しができる

### 3. 表示
- 一覧カード: 項目名の左にアイコン。**経年ステージに応じて掠れる(薄くなる)**
- 詳細シート: 見出し(項目名)の左にアイコン

## 未決だった事項の決定

- **選べるアイコンの候補一覧と件数**: 24 個 + 「指定なし」(design.md 判断1 の表)。画面イメージの例(風呂・ゴミ出し・植物・筋トレ・読書・車・ペット・カフェ)と、F13 のカテゴリ(掃除 / 健康 / 美容 / 家電 / 車 / その他)をまんべんなく覆う。歯のアイコンは Flutter 同梱の `Icons` に無いため「病院」で代える
- **既定アイコン**: `Icons.event_repeat`(繰り返しの行動を表す)

## 受け入れ条件

### 保存
- [ ] v2 → v3 のマイグレーションで既存の項目・履歴が 1 件も失われず、`icon` は NULL になる(データ検証つきのマイグレーションテスト)
- [ ] アイコンを選んで登録・編集すると、再起動後(`watchAll` の再読込)も同じアイコンで出る
- [ ] DB に未知のキーが入っていても例外にならず、未選択として扱われる

### 選択
- [ ] 登録画面でアイコンを選ばずに保存すると、既定アイコンの項目ができる
- [ ] 登録画面でアイコンを選んで保存すると、そのアイコンの項目ができる
- [ ] 編集画面は現在のアイコンが選択状態で開く。変更・「指定なし」への戻しが保存される
- [ ] 編集でアイコンだけ変えても、最終実施日・経過日数・履歴は変わらない
- [ ] 各候補は 48dp 以上のタップ領域を持ち、読み上げで日本語名と選択状態が分かる

### 表示
- [ ] 一覧カードと詳細シートにアイコンが出る。未選択なら既定アイコン
- [ ] カードのアイコンは経年ステージが進むほど薄くなる。全ステージ × 明暗で紙に対するコントラストが 3:1 以上
- [ ] アイコンは読み上げに含めない(装飾扱い。カードの読み上げ文は変えない)
- [ ] 360dp 幅・文字倍率 1.19 でカードが横並びのまま溢れない。1.2 以上で縦積みになる

## 成功指標

- 登録の 30 秒要件(PRD)を崩さない: アイコン選択は任意で、入力欄の自動フォーカスは維持する

- 図鑑画面・下部ナビ(#34)
- 項目名からのアイコン自動推定
- 候補の検索・カテゴリ別のタブ分け
