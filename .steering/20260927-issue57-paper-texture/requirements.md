# 要求: 紙の質感を画面イメージに合わせる(Issue #57)

## 背景

画面イメージ(`docs/ideas/LastWhen_gamen.png`)のカードは、和紙のような繊維感のある紙にシミ・縁の焼け・破れが載っている。
現状の経年変化(F28 / `lib/ui/widgets/aged_paper.dart`)は、単色の面・楕円のシミ・線の縁取りで近似しているだけで、質感が画面イメージに届いていない。

## やること

1. 一覧のカード(`ItemCard`)と図鑑のカード(`CollectionCard`)の紙を画面イメージの質感に寄せる(繊維・斑点・不定形のシミと輪染み・ぼかした縁の焼け・端の荒れ)
2. 経年ステージ 5 段階の違いを、画面イメージ下段「① 時間の経過でカードが古びる」の見本に合わせる
3. 画面全体の背景にごく薄く紙の地(繊維)を敷く
4. `docs/functional-design.md`「色の使い方」の「紙の表現」列を実装に合わせて改める(司令塔が担当)

## ユーザーと確定した判断(2026-09-27)

| 論点 | 決定 |
| --- | --- |
| 質感の作り方 | **描画コード(`CustomPainter`)で作り込む。** テクスチャ画像は使わない(素材・ライセンス・ダーク用画像・APK サイズの問題が出ない) |
| 背景の紙 | **敷く(ごく薄く)** |
| 詳細シートの紙 | **#58 に回す。** いまの詳細シートには紙の描画が無く、#58 で「記録の詳細」画面に作り直す際に `AgedPaperPainter` を使えば質感は揃う |

## やらないこと

- 経年ステージの境界値(0.5 / 1.0 / 1.5 / 2.0)の変更
- `ColorScheme` の配色・フォント・画面構成の変更
- 詳細シートへの紙の追加(#58)
- テクスチャ画像アセットの追加・パッケージの追加

## 受け入れ条件

- [ ] 5 段階の紙が、画面イメージ下段の見本と見比べて同じ段階だと分かる(司令塔がプレビュー画像で確認し、ユーザーに提示する)
- [ ] 紙の上のテキストのコントラストが全ステージ × 明暗で 4.5:1 以上(既存の検査 + **実際に描いた画素で測る検査**)
- [ ] 色だけに頼らず形状でも段階が分かる(シミ → 縁の焼け → 端の荒れ → 欠け、の段階的な追加を保つ)
- [ ] 項目 100 件の一覧でスクロールがカクつかない(既存の `performance_test.dart` が通る)
- [ ] `dart format` / `flutter analyze --fatal-infos` / `flutter test` が通る
