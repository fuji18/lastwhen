# 要求: 図鑑の検索中にシステムの戻るで検索を閉じる(Issue #46)

## 背景

図鑑画面(#34 / PR #45)の検索モードは AppBar 左上の戻るボタン(`_closeSearch`)でしか抜けられない。
`HomeShell` がアプリで唯一のルートのため、Android でシステムの戻るを押すと検索が閉じずに**アプリが終了する**。

- 優先度: P2(#34 と同じ)。残る唯一のオープンチケットで、ユーザーが着手を承認済み(2026-09-26)
- 種別: bug

## 受け入れ条件

- [ ] 検索モード中にシステムの戻る(Android の戻るボタン・戻るジェスチャー)を押すと、アプリを閉じずに検索が閉じる(左上のボタンを押したときと同じ状態に戻る)
- [ ] 検索モードでないときの戻るは今までどおり(アプリの既定の動き)
- [ ] 上の 2 点をウィジェットテストで確認する

## 司令塔が追加した条件

- [ ] 図鑑で検索を開いたままホームタブへ切り替えた場合、ホームでの戻るは**横取りしない**(今までどおりアプリの既定の動き)
  - 理由: `HomeShell` は `IndexedStack` で図鑑を常駐させるため、単純に `PopScope(canPop: !_searching)` とすると
    見えていない図鑑が戻るを奪い、ホームで戻るを押しても何も起きない(1 回空振りする)状態になる

## 対象外

- 他の画面の戻るボタンの挙動
- タブ切替時に検索状態を保つか消すか(現状どおり保つ)
