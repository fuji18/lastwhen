プライバシーポリシー

LastWhen — 最後にいつ

このプライバシーポリシーは、アプリ「LastWhen」(以下「本アプリ」)が利用者の情報をどう扱うかを定めるものです。本アプリの開発者(以下「開発者」)は、次のとおり取り扱います。

収集する情報

本アプリは、利用者の情報を収集しません。

  • 本アプリは、入力された内容を開発者や第三者のサーバーへ送信しません。本アプリにはインターネットに接続する機能がありません。
  • アクセス解析、広告、クラッシュレポートのためのツールを組み込んでいません。
  • アカウントの登録やログインは必要ありません。氏名・メールアドレス・位置情報などの個人情報を求めません。

端末に保存する情報

本アプリに入力した内容(項目の名前、カテゴリ、アイコン、記録した日時)は、お使いの端末の中にだけ保存します。保存先は本アプリ専用の領域で、他のアプリからは読み取れません。

OS のバックアップ

端末の OS が提供するバックアップ機能(Android の自動バックアップ、iOS の iCloud バックアップなど)が有効になっている場合、本アプリのデータもその対象に含まれ、OS の提供元(Google や Apple)のクラウドに複製が保存されます。

  • これは機種変更のときに記録を引き継げるようにするためで、本アプリはバックアップの対象から自らを除外していません。
  • バックアップの保存と送信は OS が行うもので、本アプリが送信するものではありません。開発者はそのデータを見ることができません。
  • バックアップの扱いは OS の提供元のプライバシーポリシーに従います。保存したくない場合は、端末の設定でバックアップを無効にしてください。

データの書き出し

本アプリのデータを書き出して保存・共有する機能を使った場合、書き出したファイルは、利用者が共有先を選んで操作したときにだけ端末の外へ出ます。本アプリが自動で送信することはありません。共有した先での扱いは、その共有先(アプリやサービス)の定めに従います。

通知

本アプリは、しばらく記録していない項目をお知らせするために、通知の許可を求めることがあります。

  • 通知は端末の中で予約して表示します。外部の通知配信サービスは使いません。
  • 通知には項目の名前が表示されます。ロック画面での表示は、端末の通知設定で変えられます。
  • 端末を再起動した後も通知の予約を保つため、端末の起動を検知する権限を使います。
  • 通知を許可しなくても、本アプリのほかの機能はそのまま使えます。許可は端末の設定からいつでも変えられます。

第三者への提供

開発者は利用者の情報を収集しないため、第三者に提供することもありません。

データの削除

本アプリの中で項目を削除すると、その項目と記録は端末から消えます。本アプリをアンインストールすると、端末内のデータはすべて消えます。OS のバックアップに残った複製は、端末の設定から削除してください。

このポリシーの変更

本アプリの機能の変更などに合わせて、このポリシーを改定することがあります。改定したときは、このページを更新し、下の改定日を書き換えます。

お問い合わせ

このポリシーや本アプリについてのお問い合わせは、次のいずれかで受け付けます。

  • 本アプリを入手したストア(Google Play など)の掲載ページに記載している、デベロッパーの連絡先
  • GitHub の Issues: https://github.com/fuji18/lastwhen/issues(投稿には GitHub のアカウントが必要です。投稿した内容は公開されます)
