## プロダクトビジョン

日常生活の中で「最後にこれをやったのはいつだっけ？」となる行動を、簡単に記録・確認できるアプリを作る。

美容院、歯医者、エアコン掃除、歯ブラシ交換、布団を干した日など、毎日ではないが定期的に行う生活行動は忘れやすい。

このアプリでは、行動した日に「やった」ボタンを押すだけで記録でき、前回から何日経過したかをひと目で確認できるようにする。

**一言で言うと**:

「最後にいつやった？」を、1タップで記録・確認できる生活管理アプリ。

---

## 解決したい課題

1. 美容院、歯医者、掃除、消耗品交換など、毎日ではない生活行動の最終実施日を忘れてしまう。

2. カレンダーやメモ帳に記録しても、後から探すのが面倒で継続しにくい。

3. 一般的なToDo・習慣管理アプリは、毎日・毎週のタスク管理を中心としており、「前回いつやったか」を確認する用途には機能が多すぎる。

4. 定期的ではあるものの厳密なスケジュールを設定するほどではない行動を管理しづらい。

5. 記録操作が面倒だと長続きしないため、できるだけ少ない操作で記録したい。

## ターゲットユーザー

### ペルソナ

#### メインペルソナ

- 年齢: 20〜40代
- 職業: 会社員・学生・フリーランスなど
- スマートフォンを日常的に利用している
- タスク管理アプリを使った経験はあるが、入力が面倒で続かなかった経験がある

#### 今困っていること

- 「美容院に最後に行ったのはいつ？」
- 「エアコンのフィルター、いつ掃除した？」
- 「歯ブラシをいつ交換したか分からない」
- 「布団を最後に干した日を思い出せない」
- 「車の洗車をいつしたか覚えていない」

など、日常生活のちょっとした履歴を覚えていない。

#### 欲しいもの

- アプリを開けば、前回実施日と経過日数がすぐ分かる
- 記録は1タップ程度で終わる
- 細かいスケジュール管理をしなくてよい
- 項目を自由に追加できる
- 長期間使っても管理が面倒にならない

## 主要機能の候補

### P0 (MVPで絶対必要)

1. 管理項目の一覧表示
   - 登録した項目を一覧表示する
   - 例:
     - 美容院
     - 歯医者
     - エアコン掃除
     - 歯ブラシ交換

2. 管理項目の新規登録
   - 項目名を入力して追加できる

3. 最終実施日の記録
   - 各項目に「やった」ボタンを配置する
   - ボタンを押すと現在日時を最終実施日として保存する

4. 最終実施日の表示
   - 例:
     - 2026年9月12日

5. 経過日数の表示
   - 現在日と最終実施日の差分を計算する
   - 例:
     - 3日前
     - 42日前
     - 128日前

6. 管理項目の編集
   - 項目名を変更できる

7. 管理項目の削除
   - 不要になった項目を削除できる

8. データの端末内保存
   - アプリを終了してもデータが保持される
   - MVPではログイン・サーバー同期は行わない

### P1 (重要だけど後回しでもいい)

1. 通知機能
   - 指定日数が経過した場合に通知する
   - 例:
     - 「歯ブラシ交換から30日経過しました」

2. 目安期間の設定
   - 各項目に推奨間隔を設定できる
   - 例:
     - 歯ブラシ交換: 30日
     - 美容院: 60日

3. 経過日数による状態表示
   - 目安期間に応じて状態を分かりやすくする
   - 例:
     - 余裕あり
     - そろそろ
     - 経過

4. カテゴリ機能
   - 掃除
   - 健康
   - 美容
   - 家電
   - 車
   - その他

5. アイコン設定
   - 項目ごとにアイコンを設定できる

6. 並び替え
   - 経過日数順
   - 名前順
   - 登録順

7. 過去履歴の保存
   - 最終実施日だけではなく、過去に実施した日を履歴として残す

### P2 (あったら嬉しい)

1. ホーム画面ウィジェット

2. クラウド同期

3. 複数端末同期

4. 家族との項目共有

5. テンプレート項目
   - 歯ブラシ
   - 美容院
   - エアコン掃除
   - 歯医者
   - 洗車
   - 布団干し
   などをワンタップで追加できる

6. 項目ごとのメモ

7. 写真記録
   - 掃除前後
   - 交換した商品の写真など

8. 統計表示
   - 平均実施間隔
   - 年間実施回数

9. ゲーミフィケーション
   - 実施すると経験値を獲得
   - バッジ・実績
   - キャラクターや部屋の成長

10. テーマ・カラーカスタマイズ

## 技術的な検討事項

### アプリ形態

スマートフォン向けアプリを想定する。

iOS / Androidの両方で利用できる構成が望ましい。

### フロントエンド候補

以下のいずれかを検討する。

- Flutter
- React Native / Expo

個人開発かつクロスプラットフォーム開発を優先する。

### データ保存

MVPではサーバーを利用せず、端末内に保存する。

候補:

- SQLite
- Flutterの場合: Drift / sqflite / Isar等
- React Nativeの場合: SQLite / AsyncStorage等

単純なデータ構造であればローカルストレージでも実装可能だが、将来的な履歴機能を考慮してSQLite系を優先的に検討する。

### 想定データ

管理項目には最低限以下を保持する。

- ID
- 項目名
- 最終実施日時
- 作成日時
- 更新日時

P1以降では以下を追加する可能性がある。

- カテゴリ
- アイコン
- 目安日数
- 通知設定
- 並び順

### バックエンド

MVPでは使用しない。

クラウド同期やアカウント機能を実装する場合に後から追加する。

候補:

- Firebase
- Supabase
- 独自API

### 認証

MVPでは実装しない。

## 非機能要件(とりあえず)

### 使いやすさ

- アプリ起動後すぐ一覧を確認できること
- 「やった」の記録を1タップで行えること
- 基本操作を説明なしでも理解できるUIにすること

### パフォーマンス

- 起動から一覧表示まで体感的に待たせない
- 項目数100件程度でも快適に操作できること

### オフライン対応

- インターネット接続なしですべてのP0機能を利用できること

### 信頼性

- アプリ再起動後もデータが消えないこと
- 誤操作で記録した場合に修正できることを将来的に検討する

### プライバシー

- MVPではユーザーデータを外部サーバーへ送信しない
- 端末内で完結する設計を基本とする

### UI

- スマートフォンの片手操作を意識する
- 最終実施日よりも「何日前」を視覚的に強調する
- 項目追加までの操作数を少なくする
- 情報量を増やしすぎず、シンプルな画面構成にする

## 成功指標(とりあえず)

### ユーザー視点

1. 管理項目を30秒以内に登録できる

2. 「最後にいつやったか」をアプリ起動後5秒以内に確認できる

3. 実施記録を1〜2タップ以内で完了できる

4. 1週間後も継続して記録しているユーザーがいる

5. カレンダーやメモ帳を探さなくても生活履歴を確認できる

### プロダクト視点

MVP段階では以下を確認する。

- 初回起動時の項目登録率
- 1ユーザーあたりの平均登録項目数
- 「やった」ボタンの利用回数
- 7日後継続率
- 30日後継続率

初期目標:

- 平均登録項目数: 5件以上
- 初回利用時に3件以上登録するユーザー: 50%以上
- 7日後継続率: 30%以上

正式リリース後は通知機能による再訪率なども評価する。
